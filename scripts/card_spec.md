# 학습 카드 작성 규칙

고등학교 수학 교사가 사례 하나를 스스로 공부하기 위한 학습 카드를 쓴다. 한국어로 쓴다.

## 형식
- 절 제목은 줄 맨 앞의 "## "로만 쓴다. 다른 수준의 제목(#, ###)과 표는 쓰지 않는다.
- 수식은 LaTeX로 쓴다. 문장 안에서는 $...$, 따로 떼는 식은 한 줄에 $$...$$ 하나만 쓴다. $$ 안에서 줄바꿈하지 않는다.
- KaTeX가 그릴 수 있는 명령만 쓴다(\frac, \sqrt, \ln, \sin, \left( \right), \text{}, \begin{aligned} 등). \newcommand, \label, \tag 는 쓰지 않는다.
- 문장은 "~입니다/합니다" 체로, 짧고 분명하게 쓴다. 줄표(—)로 끼워 넣는 말, 과장된 수식어, 느낌표는 쓰지 않는다.

## 내용 원칙
- 사례 원문(points)은 자동 생성된 자료라 검증되지 않았다. 수식은 직접 유도해 맞는지 확인하고, 틀리거나 비약이 있으면 고친 식을 쓴다. 고친 내용은 마지막 절에 밝힌다.
- 확실하지 않은 내용은 "불확실"이라고 쓰고 지어내지 않는다. 출처 없는 실제 수치(제품 성능, 통계, 연도)를 꾸며 내지 않는다. 계산 예시에 쓰는 숫자는 "예를 들어"라고 밝힌 가정값으로 둔다.
- 확인 문제의 답은 직접 계산해 맞는지 확인한다.
- 해당 과목의 교육과정을 넘는 개념(미분방정식, 편미분, 행렬 분해 등)이 나오면 "교육과정 밖"이라고 표시한다.

## 절 구성 (이 제목 그대로, 이 순서로, 모두 포함)
## 한눈에
세 문장: 무슨 기술인지, 어떤 수학이 쓰이는지, 왜 배울 만한지.
## 쉬운 설명
비전공자도 알 수 있게 일상 비유로 원리를 설명한다. 6~9문장.
## 용어 풀이
낯선 용어마다 "- **용어**: 뜻" 한 줄. 4~7개.
## 수식 한 줄씩
사례의 핵심 수식 2~4개. 수식마다 $$ 한 줄, 그 아래에 무엇을 뜻하는지, 기호와 단위, 어디서 나오는지, 숨은 가정을 2~4문장으로.
## 문답
교사가 물을 만한 질문 4개와 답. "**Q.** 질문" 다음 줄에 "**A.** 답". 뒤로 갈수록 깊어지게.
## 확인 문제
3문제. "1. 문제" 다음 줄에 "**정답과 풀이** …". 고교 수준에서 풀 수 있게.
## 다음 공부
"- " 목록 4줄: 먼저 알아야 할 개념 2개, 이어서 볼 개념 2개. 각 한 줄.
## 원본에서 고친 점
고친 것이 없으면 "없음".

분량은 수식을 포함한 전체 글자 수로 카드 하나에 3,200~5,000자 정도.

## 핵심 수식과 그래프 (카드마다 `<사례ID>.fig.json` 을 함께 쓴다)

카드 맨 위에 크게 보여 줄 핵심 수식 하나와, 값을 바꿔 가며 볼 그래프 정보를 JSON 으로 쓴다. 카드 본문(.md)에는 넣지 않는다.

```json
{
  "key": "D(v) = C_1 v^2 + \\dfrac{C_2}{v^2}",
  "say": "두 항이 같아지는 속도에서 항력이 가장 작습니다.",
  "plot": {
    "xLabel": "속도 v (m/s)", "yLabel": "항력 (N)",
    "x": [20, 110], "y": [0, 5000],
    "curves": [
      { "label": "유해 항력", "expr": "0.4*x^2" },
      { "label": "유도 항력", "expr": "2.5e6/x^2" },
      { "label": "총 항력", "expr": "0.4*x^2 + 2.5e6/x^2" }
    ],
    "start": 50,
    "marks": [{ "x": 50, "label": "최소" }],
    "note": "예를 들어 C₁ = 0.4, C₂ = 2.5×10⁶ 으로 가정했습니다."
  }
}
```

- `key`: 카드에서 가장 중요한 식 하나의 LaTeX($ 없이). "수식 한 줄씩"에 있는 식 가운데 고른다.
- `say`: 그 식에서 기억할 것을 한 문장으로(60자 안팎, 최대 90자). 합니다체.
- `plot`: 카드의 핵심 관계가 실수 변수 하나의 함수로 그려질 때만 쓴다. 행렬 곱의 성질처럼 그래프로 보여 줄 것이 없으면 `"plot": null` 로 둔다. 억지로 만들지 않는다.
  - `curves` 는 1~3개. 여러 개일 때는 "부분들과 그 합"처럼 서로 비교할 뜻이 있어야 하고, 가장 중요한 곡선을 마지막에 둔다. `label` 은 16자 이내.
  - `expr` 문법: 변수는 `x` 하나. 수(`1.5`, `2.5e6`), `+ - * / ^`, 괄호, 함수 `sin cos tan exp ln log10 sqrt abs floor round min max`, 상수 `pi`, `e`. 곱셈은 반드시 `*` 로 쓴다(`2x` 가 아니라 `2*x`). 다른 글자 변수는 쓸 수 없으므로 상수에는 예시 값을 넣는다.
  - 상수의 예시 값은 카드의 확인 문제에서 쓴 값과 같게 한다. 그래야 그래프에서 읽은 값이 문제의 정답과 맞는다. 가정한 값은 `note` 에 밝힌다(120자 이내).
  - `x`, `y` 는 [최소, 최대]. 극값, 교점, 점근 같은 특징이 범위 안에 들어오게 잡는다. 범위를 벗어난 부분은 잘려 보인다. 축 이름에는 단위를 넣는다.
  - `start` 는 처음에 가리킬 x 값, `marks` 는 세로 점선으로 표시할 x 값(0~2개, `label` 14자 이내).
- 쓰기 전에 python3 로 범위 안의 값을 계산해 보고, 표시한 x 에서 곡선이 실제로 그런 특징(최소, 교점 등)을 갖는지 확인한다.
