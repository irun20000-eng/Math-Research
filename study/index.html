1조건 여섯 개

정지에서 출발해 정지로 끝나는 이동에서 처음과 끝의 위치·속도·가속도를 정하면 5차 다항식이 단 하나로 정해집니다.

2식 하나
y=W\,(10\tau^3-15\tau^4+6\tau^5)

\tau=t/T. 거리 W 와 시간 T 만 바꾸면 모든 경우에 쓰입니다.

3가장 부드러운 길

같은 조건을 만족하는 모든 움직임 가운데 이 식이 저크 제곱의 합을 가장 작게 만듭니다.

3단계 · 수식 세우기

조건 여섯 개에서 식까지

수학Ⅱ의 다항함수 미분과 연립방정식만 씁니다. 다섯 걸음입니다.

조건을 적는다

시간 0\le t\le T 동안 옆으로 W 만큼 옮깁니다. 처음과 끝에서 멈춰 있고 힘도 걸리지 않게 합니다.

y(0)=0,\ \ y'(0)=0,\ \ y''(0)=0,\qquad y(T)=W,\ \ y'(T)=0,\ \ y''(T)=0

조건이 여섯 개이므로 계수가 여섯 개인 5차 다항식으로 놓습니다.

y(t)=a_0+a_1t+a_2t^2+a_3t^3+a_4t^4+a_5t^5

출발 조건으로 계수 세 개를 지운다

y(0)=a_0,\ \ y'(0)=a_1,\ \ y''(0)=2a_2 이므로 a_0=a_1=a_2=0 입니다.

y(t)=a_3t^3+a_4t^4+a_5t^5
원본 문서와 연결
주차 문서의 y(t)=c_5t^5+c_4t^4+c_3t^3 이 바로 이 꼴입니다.

도착 조건으로 연립방정식을 세운다

계산을 간단히 하려고 b_3=a_3T^3,\ b_4=a_4T^4,\ b_5=a_5T^5 로 둡니다.

\begin{aligned} b_3+b_4+b_5&=W &&\text{(위치)}\\ 3b_3+4b_4+5b_5&=0 &&\text{(속도)}\\ 6b_3+12b_4+20b_5&=0 &&\text{(가속도)} \end{aligned}

푼다

가셋째 ÷ 2 − 둘째
2b_4+5b_5=0

b_4=-\tfrac52b_5

나둘째에 대입
3b_3-5b_5=0

b_3=\tfrac53b_5

다첫째에 대입
\left(\tfrac53-\tfrac52+1\right)b_5=W

\tfrac16b_5=W

b_5=6W,\qquad b_4=-15W,\qquad b_3=10W

정리하고 미분한다

τ = t/T 로 쓰면 모양 함수 s 하나로 정리됩니다
y(t)=W\,s(\tau),\qquad s(\tau)=10\tau^3-15\tau^4+6\tau^5
속도
s'=30\tau^2(1-\tau)^2
가속도
s''=60\tau(1-\tau)(1-2\tau)
저크
s'''=60(1-6\tau+6\tau^2)

t 로 미분할 때마다 1/T 이 하나씩 붙어, 속도는 W/T, 가속도는 W/T^2, 저크는 W/T^3 에 비례합니다.

속도가 가장 클 때
\tau=\frac12,\quad \frac{15}{8}\cdot\frac{W}{T}

s''=0 의 가운데 근

가속도가 가장 클 때
\tau=\frac{3\mp\sqrt3}{6},\quad \frac{10}{\sqrt3}\cdot\frac{W}{T^2}

s'''=0 의 두 근

저크가 가장 클 때
\tau=0,\ 1,\quad 60\cdot\frac{W}{T^3}

이차함수의 구간 끝값

수업 연결
가속도의 극값은 가속도를 한 번 더 미분한 저크가 0인 곳에서 찾습니다. "도함수가 0인 곳이 극값 후보"를 한 단계 위 도함수에 그대로 쓰는 셈입니다.
4단계 · 만져 보기

시간, 거리, 노면을 바꿔 보기

곡선 종류와 슬라이더를 바꿔 네 그래프와 한계 판정이 어떻게 달라지는지 봅니다.
마찰원
타이어가 낼 수 있는 힘의 한계를 원으로 나타낸 것입니다. 앞뒤 가속도 a_x 와 옆 가속도 a_y 를 합친 크기가 \mu g 를 넘으면 미끄러집니다.
최소 회피 시간
a_x^2+a_y^2\le(\mu g)^2\ \Longrightarrow\ \frac{10}{\sqrt3}\frac{W}{T^2}\le\sqrt{(\mu g)^2-a_x^2}\ \Longrightarrow\ T\ge\sqrt{\frac{10\,W}{\sqrt3\,\sqrt{(\mu g)^2-a_x^2}}}
이 모델의 가정
차를 한 점으로 보고, 앞으로 가는 속도는 일정하며, 차의 방향이 진행 방향에서 조금만 벗어난다고 봅니다. 실제 차량은 하중 이동, 조향 지연, 타이어 특성이 더해지므로 여기서 구한 시간은 "이보다 빨리는 안 된다"는 아래쪽 한계입니다.
5단계 · 한 걸음 더

왜 하필 5차인가

조건 여섯 개를 맞추는 함수는 많습니다. 그 가운데 5차식이 특별한 이유입니다.
교육과정 밖
부분적분만 알면 따라갈 수 있습니다. 학생에게는 결과만 인용하게 하는 편이 맞습니다.
1무엇을 줄이나

이동 전체의 저크 크기를 이 값으로 잽니다.

J[y]=\int_0^T (y''')^2\,dt
2다른 함수와 비교

5차식 y 와 같은 조건의 다른 함수 y+\eta. 차이 \eta 는 양 끝에서 \eta=\eta'=\eta''=0.

3 · 전개하면 세 항이 나옵니다
J[y+\eta]=J[y]+2\int_0^T y'''\eta'''\,dt+\int_0^T(\eta''')^2\,dt
4 · 가운데 항을 부분적분으로 세 번 옮깁니다. 경계값은 모두 0이고, 5차식을 여섯 번 미분하면 0입니다
\int_0^T y'''\eta'''\,dt=-\int_0^T y^{(4)}\eta''\,dt=\int_0^T y^{(5)}\eta'\,dt=-\int_0^T y^{(6)}\eta\,dt=0
결론
J[y+\eta]=J[y]+\int(\eta''')^2dt\ \ge\ J[y]

어떤 다른 함수도 5차식보다 저크가 작을 수 없습니다.

최솟값
J_{\min}=\frac{720\,W^2}{T^5}

\int_0^1 3600(1-6\tau+6\tau^2)^2d\tau=720

배경
함수마다 수를 대응시키고 그 수를 최소로 하는 함수를 찾는 방법이 변분법입니다. 사람이 손을 뻗는 궤적이 이 최소 저크 곡선과 잘 맞는다는 것을 보인 연구가 Flash와 Hogan(1985)입니다.
6단계 · 문답

물을 만한 질문 다섯 개

먼저 스스로 답해 보고 눌러서 확인하세요.
Q가속도까지 0으로 맞출 필요가 있나요? 속도만 0이면 충분하지 않나요?

속도만 맞춘 3차식 s=3\tau^2-2\tau^3 은 가속도가 s''=6-12\tau 라서 출발 순간 6W/T^2 입니다. 출발 전에는 0이었으므로 가속도가 뛰고 저크는 무한대가 됩니다.

4단계에서 "3차식으로 바꾸기"를 눌러 가속도 그래프의 양 끝을 보세요.

Q차수를 7차로 올리면 더 좋아지나요?

7차식 s=35\tau^4-84\tau^5+70\tau^6-20\tau^7 은 저크까지 양 끝에서 0입니다. 대신 최대 가속도가 7.51\,W/T^2 로 5차의 약 1.3배입니다.

끝을 부드럽게 만들수록 가운데에서 더 세게 움직여야 합니다. 타이어 한계가 문제라면 오히려 불리합니다.

Q실제 자율주행차가 정말 이 식으로 움직이나요?

5차 다항식은 궤적 계획에서 널리 쓰이는 기본 재료입니다. 실제 시스템은 여러 후보 궤적을 만들어 장애물, 차량 한계, 승차감을 함께 따져 고르거나 수치 최적화를 씁니다.

특정 제조사가 어떤 식을 쓰는지는 이 강좌에서 확인하지 못했습니다(불확실).

Q학생에게 저크를 소개해도 교육과정에 맞나요?

수학Ⅱ는 위치 → 속도 → 가속도까지 다룹니다. 저크는 용어만 새로울 뿐 "다항함수를 한 번 더 미분한다"는 계산이라 탐구 주제로 무리가 없습니다.

5단계의 변분법 증명은 교육과정 밖이므로 결과만 인용하게 하세요.

Q원본 문서의 수식은 믿어도 되나요?

이 주제에 한해서는 맞습니다. 식의 꼴, 가속도 극값을 y'''=0 으로 찾는다는 설명, 마찰원 조건 모두 이 강좌의 유도와 일치합니다.

문서에는 계수 값과 최댓값 수치가 빠져 있어 여기서 채웠습니다.

8단계 · 예시 자료

수업에 바로 쓸 것들

탭을 골라 보고 복사하세요. 수식은 LaTeX로 복사됩니다.
수업 첫 5분
엘리베이터가 출발할 때와 멈출 때, 몸이 "덜컥" 하는 순간은 정확히 언제일까요? 빠르게 움직일 때일까요, 속도가 바뀔 때일까요, 아니면 다른 무엇이 바뀔 때일까요?

학생 답을 "속도", "가속도", "그 밖"으로 나눠 적은 뒤, 위치를 세 번 미분한 양을 소개합니다.

교과서 수준
함수 f(x)=10x^3-15x^4+6x^5\ (0\le x\le1) 에 대하여 f'(x) 의 최댓값과 그때의 x 의 값을 구하시오.
f'(x)=30x^2(1-x)^2. x(1-x) 는 x=\tfrac12 에서 최댓값 \tfrac14 이므로 f'(x)\le\tfrac{30}{16}=\tfrac{15}{8}. 답: x=\tfrac12 에서 \tfrac{15}{8}.
표준
위 함수에 대하여 g(x)=f''(x) 라 할 때, 구간 [0,1] 에서 g(x) 의 최댓값을 구하시오.
g'(x)=60(1-6x+6x^2)=0 에서 x=\tfrac{3\pm\sqrt3}{6}. 작은 근에서 극대. g(x)=60x(1-x)(1-2x) 에 x(1-x)=\tfrac16,\ 1-2x=\tfrac{\sqrt3}{3} 을 넣으면 \tfrac{10\sqrt3}{3}. 구간 끝값은 0이므로 최댓값은 \tfrac{10\sqrt3}{3}.
심화
다항함수 f(x)=ax^5+bx^4+cx^3 이 f(1)=1,\ f'(1)=0,\ f''(1)=0 을 만족시킬 때, 상수 a,b,c 의 값을 구하고 f'(x)\ge0 임을 보이시오.
a+b+c=1,\ 5a+4b+3c=0,\ 20a+12b+6c=0. 셋째에서 10a+6b+3c=0, 둘째를 빼면 5a+2b=0. 정리하면 a=6,\ b=-15,\ c=10. f'(x)=30x^2(x-1)^2\ge0.
실생활 적용
자율주행차가 T 초 동안 옆으로 3.5 m 옮기는 궤적을 y(t)=3.5\left(10\tau^3-15\tau^4+6\tau^5\right),\ \tau=t/T 로 정했다. 옆 방향 가속도의 최댓값이 \tfrac{10}{\sqrt3}\cdot\tfrac{3.5}{T^2} 일 때, 이 값이 7.84\ \mathrm{m/s^2} 이하가 되는 T 의 최솟값을 소수 첫째 자리까지 구하시오.
T^2\ge\dfrac{10\times3.5}{\sqrt3\times7.84}\approx2.577 이므로 T\ge1.605\ldots. 답: 약 1.6초 (올림하면 1.7초부터 안전).
네 그래프와 검산
import numpy as np
import matplotlib.pyplot as plt

W, T = 3.5, 2.5          # 옮기는 거리(m), 이동 시간(s)
mu, g = 0.8, 9.8         # 마찰계수, 중력가속도

t = np.linspace(0, T, 500)
x = t / T
y = W * (10*x**3 - 15*x**4 + 6*x**5)
v = W / T    * 30 * x**2 * (1 - x)**2
a = W / T**2 * 60 * x * (1 - x) * (1 - 2*x)
j = W / T**3 * 60 * (1 - 6*x + 6*x**2)

# 검산: 수식으로 구한 최댓값과 비교
print(v.max(), 15/8 * W/T)
print(a.max(), 10/np.sqrt(3) * W/T**2)
print("최소 회피 시간:", np.sqrt(10*W / (np.sqrt(3)*mu*g)))

fig, ax = plt.subplots(4, 1, sharex=True, figsize=(6, 8))
for k, (f, name) in enumerate([(y, "y (m)"), (v, "v (m/s)"), (a, "a (m/s²)"), (j, "jerk (m/s³)")]):
    ax[k].plot(t, f); ax[k].set_ylabel(name); ax[k].grid(alpha=.3)
ax[2].axhline(mu*g, ls="--"); ax[2].axhline(-mu*g, ls="--")
ax[3].set_xlabel("t (s)"); plt.tight_layout(); plt.show()
