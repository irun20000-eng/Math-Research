1경계 조건 여섯 개

정지에서 출발해 정지로 끝나는 이동에서 처음(t=0)과 끝(t=T)의 위치·속도·가속도 6개를 지정하면 5차 다항식이 유일하게 결정됩니다.

2무차원 정규화 식 하나
y(\tau)=W\,(10\tau^3-15\tau^4+6\tau^5)

무차원 시간 \tau=t/T\in[0,1]를 쓰면 이동 폭 W와 시간 T만 바꿔 모든 공학 문제에 그대로 적용됩니다.

3최소 저크(Minimum Jerk) 최적성

같은 여섯 조건을 만족하는 모든 미분가능 함수 가운데 이 5차식이 저크 제곱의 적분값 \int_0^T (y''')^2 dt을 최소로 만듭니다.

버스나 엘리베이터에 서 있을 때 몸이 '덜컥' 휘청이는 순간을 수학으로 구분해 봅시다.

일정한 속도 (y''=0)

등속 직선 운동에서는 알짜힘이 0입니다. 손잡이를 잡지 않아도 편안하게 서 있을 수 있습니다.

일정한 가속도 (y'''=0)

일정한 힘이 걸리므로 몸을 살짝 기울이면 균형을 유지할 수 있습니다. 근육이 예측 가능한 상태입니다.

가속도가 급변할 때 (|y'''|\gg 0)

급브레이크를 밟거나 떼는 순간 가속도가 불연속적으로 뛰면 승객이 휘청거리고 기계 관절에 충격파가 걸립니다. 이 가속도의 시간 변화율이 바로 저크(Jerk, y''')입니다.

위치에서 저크까지의 미분 계층 (수학Ⅱ → 물리·공학 확장)
y(t)\ \xrightarrow{\ \frac{d}{dt}\ }\ v(t)=y'(t)\ \xrightarrow{\ \frac{d}{dt}\ }\ a(t)=y''(t)\propto F(t)\ \xrightarrow{\ \frac{d}{dt}\ }\ j(t)=y'''(t)\propto \frac{dF}{dt}

시간 [0, T] 동안 옆으로 W만큼 이동하는 6개의 경계조건

출발 순간(t=0)과 도착 순간(t=T)에 차선이 평행하고 조향각(횡가속도)이 0이어야 핸들을 꺾는 충격이 없습니다.

y(0)=0,\quad y'(0)=0,\quad y''(0)=0,\qquad y(T)=W,\quad y'(T)=0,\quad y''(T)=0

독립된 선형 조건이 6개이므로 미정계수 6개를 갖는 5차 다항식을 세웁니다.

y(t)=a_0+a_1t+a_2t^2+a_3t^3+a_4t^4+a_5t^5

출발 조건(t = 0)으로 상수항·일차항·이차항 소거

t=0을 대입하면 y(0)=a_0=0, y'(0)=a_1=0, y''(0)=2a_2=0이므로 처음 세 계수가 즉시 사라집니다.

y(t)=a_3t^3+a_4t^4+a_5t^5
드라이브 원본 문서와의 연결
주간 리서치 문서에 등장하는 y(t)=c_5t^5+c_4t^4+c_3t^3 형태가 바로 t=0 초기 조건 3개를 적용한 직후의 식입니다.

도착 조건(t = T)과 치환으로 연립방정식 세우기

계산을 깔끔하게 하기 위해 b_3=a_3T^3,\ b_4=a_4T^4,\ b_5=a_5T^5로 치환하고 t=T에서의 조건을 적습니다.

\begin{aligned} b_3 + b_4 + b_5 &= W && \text{— 위치 } y(T)=W \\ 3b_3 + 4b_4 + 5b_5 &= 0 && \text{— 속도 } T\cdot y'(T)=0 \\ 6b_3 + 12b_4 + 20b_5 &= 0 && \text{— 가속도 } T^2\cdot y''(T)=0 \end{aligned}

삼원일차연립방정식 풀기

가(식3)÷2 − (식2)
2b_4+5b_5=0 \implies b_4=-\frac{5}{2}b_5
나(식2)에 대입
3b_3-5b_5=0 \implies b_3=\frac{5}{3}b_5
다(식1)에 대입
\left(\frac{5}{3}-\frac{5}{2}+1\right)b_5=\frac{1}{6}b_5=W
b_5=6W,\qquad b_4=-15W,\qquad b_3=10W

정규화 모양 함수 s(τ)와 1·2·3계 도함수

무차원 시간 τ = t/T (0 ≤ τ ≤ 1)에 대한 표준형
y(t)=W\,s(\tau),\qquad s(\tau)=10\tau^3-15\tau^4+6\tau^5
속도 계수
s'(\tau)=30\tau^2(1-\tau)^2

\tau=1/2에서 최댓값 15/8=1.875

가속도 계수
s''(\tau)=60\tau(1-\tau)(1-2\tau)

\tau=\frac{3\mp\sqrt3}{6}에서 최댓값 \frac{10}{\sqrt3}\approx 5.774

저크 계수
s'''(\tau)=60(1-6\tau+6\tau^2)

\tau=0,1에서 최댓값 60

우측 실시간 실험실 연동
오른쪽 패널 상단 탭을 [실시간 매개변수 실험실]로 전환하면 슬라이더와 시나리오 프리셋(급회피, 빗길, 복합 제동, 3차·7차 비교)을 즉시 조작할 수 있습니다.
타이어 마찰원(Kamm's Circle) 구속 조건과 최소 회피 시간 부등식
a_x^2 + a_{y,\max}^2 \le (\mu g)^2 \implies \left(\frac{10}{\sqrt{3}}\frac{W}{T^2}\right)^2 \le (\mu g)^2 - a_x^2 \implies T_{\min} = \sqrt{\frac{10\,W}{\sqrt{3}\,\sqrt{(\mu g)^2 - a_x^2}}}
왜 제동과 조향을 동시에 하면 위험할까?

브레이크(a_x)가 마찰원 반지름 \mu g의 상당 부분을 소모하면, 옆 방향 회피에 쓸 수 있는 가용 가속도 a_{y,\text{avail}}=\sqrt{(\mu g)^2-a_x^2}이 급감하여 필요 회피 시간 T_{\min}이 길어집니다.

차수별 상충 관계 (3차 vs 5차 vs 7차)

3차식은 최대 가속도가 6W/T^2이고 양 끝에서 가속도가 불연속입니다. 7차식은 양 끝 저크까지 0이지만 최대 가속도가 7.51W/T^2로 커져 타이어 한계를 더 쉽게 넘습니다.

1목적 범함수 정의

이동 구간 동안 발생하는 저크 제곱의 총합을 비용 함수로 정의합니다.

J[y]=\int_0^T \bigl(y'''(t)\bigr)^2\,dt
2임의의 섭동 함수 \eta(t) 도입

5차식 y(t)와 동일한 6개 경계조건을 만족하는 임의의 함수를 y(t)+\eta(t)라 두면, 차이 함수 \eta는 양 끝(t=0, T)에서 \eta=\eta'=\eta''=0입니다.

3 · 제곱 전개 후 교차항에 부분적분 3회 연속 적용
J[y+\eta] = J[y] + 2\int_0^T y'''\eta'''\,dt + \int_0^T (\eta''')^2\,dt
\int_0^T y'''\eta'''\,dt = \Bigl[y'''\eta''\Bigr]_0^T - \int_0^T y^{(4)}\eta''\,dt = \cdots = -\int_0^T y^{(6)}(t)\,\eta(t)\,dt = 0
핵심 통찰: 5차 다항식을 6번 미분하면 항등적으로 0이다!
y(t)가 5차 다항식이므로 y^{(6)}(t)\equiv 0이고, 양 끝 경계항은 \eta=\eta'=\eta''=0에 의해 모두 소거됩니다. 따라서 J[y+\eta]=J[y]+\int_0^T(\eta''')^2dt \ge J[y]가 되어 등호는 \eta\equiv 0일 때만 성립합니다. (Flash & Hogan, 1985)
Q1가속도까지 0으로 맞출 필요가 있나요? 속도만 0이면 충분하지 않나요?

속도만 양 끝에서 0으로 맞춘 3차 다항식 s(\tau)=3\tau^2-2\tau^3은 가속도가 s''(\tau)=6-12\tau여서 출발 순간 6W/T^2으로 불연속 점프를 합니다. 자동차로 치면 출발 순간 핸들을 순간이동으로 꺾어야 한다는 뜻이라 물리적으로 불가능하며 큰 저크 충격이 발생합니다.

Q2차수를 7차로 올리면 더 부드럽고 좋아지나요?

양 끝에서 저크까지 0으로 맞추면 7차식 s(\tau)=35\tau^4-84\tau^5+70\tau^6-20\tau^7이 됩니다. 출발·도착은 더 부드럽지만, 정해진 시간 T 안에 이동을 마쳐야 하므로 중간 구간의 최대 가속도가 7.51W/T^2로 5차식(5.77W/T^2)보다 약 30% 커집니다. 긴급 회피처럼 타이어 마찰 한계가 중요한 상황에서는 오히려 불리합니다.

Q3학생들에게 '저크(Jerk)' 개념을 소개해도 2015/2022 개정 교육과정에 맞나요?

수학Ⅱ에서는 위치 → 속도(1계 도함수) → 가속도(2계 도함수)까지 다룹니다. 저크는 용어만 새로울 뿐 수학적으로는 "다항함수를 한 번 더 미분해 가속도의 극값과 변화율을 분석한다"는 활동이므로 수학Ⅱ 세특 심화 탐구로 매우 자연스럽습니다.

Q4원본 구글 드라이브 문서의 수식에는 누락이나 오류가 없었나요?

원본 문서의 y(t)=c_5t^5+c_4t^4+c_3t^3 꼴과 y'''(t)=0에서 가속도 극값을 구한다는 논리는 정확합니다. 다만 원본에는 구체적 계수(10, -15, 6)와 최대 가속도 상수(10/\sqrt3)가 생략되어 있어 이 연수 페이지에서 완전히 유도해 보충했습니다.

수업 첫 5분 도입 발문

"엘리베이터나 버스가 출발하고 멈출 때 우리 몸이 '덜컥' 하고 쏠리는 순간은 정확히 언제일까요? 속도가 가장 빠를 때일까요, 가속도가 가장 클 때일까요, 아니면 가속도가 변하는 순간일까요?"

학생들의 대답을 칠판에 분류한 뒤, 위치를 세 번 미분한 도함수 y'''(t)가 승차감을 결정한다는 사실로 다항함수 미분 단원을 여는 흐름입니다.

수준 1 · 교과서 기본
함수 f(x)=10x^3-15x^4+6x^5\ (0\le x\le 1)에 대하여 도함수 f'(x)의 최댓값과 그때의 x의 값을 구하시오.
해설: f'(x)=30x^2(1-x)^2=30\{x(1-x)\}^2이므로 x=\tfrac12에서 최댓값 30\times\tfrac{1}{16}=\tfrac{15}{8}=1.875를 갖습니다.
수준 2 · 내신 표준
위 함수 f(x)에 대하여 이계도함수 g(x)=f''(x)라 할 때, 닫힌구간 [0,1]에서 g(x)의 최댓값을 구하시오.
해설: g'(x)=60(1-6x+6x^2)=0에서 x=\tfrac{3-\sqrt3}{6}일 때 극대이자 최대이며, 대입하면 g_{\max}=\tfrac{10\sqrt3}{3}\approx 5.774입니다.
수준 3 · 심화 서술형
오차다항함수 f(x)=ax^5+bx^4+cx^3이 f(1)=1,\ f'(1)=0,\ f''(1)=0을 만족시킬 때 상수 a,b,c를 구하고, 구간 [0,1]에서 f(x)가 단조증가함을 보이시오.
해설: 연립방정식을 풀면 a=6,\ b=-15,\ c=10이며, f'(x)=30x^2(1-x)^2\ge 0이므로 구간 전체에서 단조증가합니다.
수준 4 · 모빌리티 융합 탐구
자율주행차가 T초 동안 옆 차선으로 W=3.5\,\text{m} 이동할 때 최대 횡가속도는 a_{\max}=\tfrac{10}{\sqrt3}\tfrac{W}{T^2}이다. 노면 한계 가속도가 7.84\,\text{m/s}^2일 때 미끄러지지 않는 최소 시간 T를 구하시오.
해설: T^2 \ge \dfrac{35}{\sqrt3\times 7.84}\approx 2.577 \implies T_{\min}\approx 1.61\,\text{s} (약 1.7초 이상 필요).
Python (NumPy · Matplotlib) 궤적 및 마찰 한계 검산 코드
import numpy as np
import matplotlib.pyplot as plt

W, T = 3.5, 2.5          # 횡이동 거리(m), 이동 시간(s)
mu, g = 0.8, 9.8         # 마찰계수, 중력가속도(m/s^2)

t = np.linspace(0, T, 500)
tau = t / T
y = W * (10*tau**3 - 15*tau**4 + 6*tau**5)
v = (W / T)    * 30 * tau**2 * (1 - tau)**2
a = (W / T**2) * 60 * tau * (1 - tau) * (1 - 2*tau)
j = (W / T**3) * 60 * (1 - 6*tau + 6*tau**2)

print(f"최대 속도 검산: 수치={v.max():.4f}, 이론={15/8 * W/T:.4f} m/s")
print(f"최대 가속도 검산: 수치={a.max():.4f}, 이론={10/np.sqrt(3) * W/T**2:.4f} m/s^2")
print(f"최소 회피 시간 T_min = {np.sqrt(10*W / (np.sqrt(3)*mu*g)):.3f} s")
